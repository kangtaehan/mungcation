# 동반 여부 미확인 표시와 자료 연결 개선

피자시티·쌍용각은 현재 포함된 문화시설 자료와 음식점 등록 목록에서 찾지 못했다. 이름만으로 지점과 입장 규정을 추정하지 않는다. 미확인은 동반 불가를 뜻하지 않으며, 자료가 추가되거나 운영사 근거가 확인되기 전에는 허용으로 표시하지 않는다.

## 수정

- 지도 첫 진입, 이름 검색, 종류별 검색을 동반 가능 자료가 있는 장소로 제한한다. 일반 장소로 전환하는 기능을 제거했다. 동물병원·놀이터도 예외 없이 같은 기준을 적용한다. 검색 응답과 주변 추천을 받은 뒤에도 다시 검사하며, 지도 핀을 생성하기 전에도 검사한다. 동반 가능 또는 조건부 동반 상태에 출처가 있어야 표시하고, 미확인·동반 불가·출처 없는 허용 상태는 제외한다.
- 일반 공원 검색도 동반 자료를 연결한다. 동일 이름과 100m 이내 좌표에 더해 동일 ID, 구조화된 도로명·건물번호, 공백을 제외한 전체 주소 중 하나가 일치해야 한다. 중복 후보는 연결하지 않는다. 공원에는 여행지·공원 자료만 연결해 인접 카페의 허용 규정을 옮기지 않는다.
- 공원 이름·좌표·공공데이터 출처는 유지하고 동반 규정만 결합한다. 동반 검색에서 동일 장소가 두 출처에 존재하면 중복을 제거한다.
- 과거에 저장한 즐겨찾기 상세도 현재 앱의 자료를 다시 조회한다. 조회 중·조회 실패·자료 없음은 구분하고 실패 시 재시도할 수 있다. 길찾기에는 갱신된 장소를 전달하며 개인 메모는 보존한다.

여기서 갱신은 앱에 포함된 자료와의 재연결이다. 전국 모든 매장의 실시간 입장 정책을 확인하는 기능은 아니다. 등록 근거가 있어도 구역 제한, 체중, 유모차 또는 캐리어 조건과 원자료 기준일을 함께 확인해야 한다.

## 검증

미확인·동반 불가·출처 없는 허용 정보가 섞인 검색 응답, 주변 추천, 종류 검색, 과거 즐겨찾기에서 길찾기로 전달된 장소가 지도 핀에 포함되지 않는지 검사한다. 조건부 동반 장소와 입장 규정은 유지한다. 공원 동일성·모호한 후보 제외, 실제 공공데이터 간 연결, 저장된 장소의 재조회·실패 후 재시도·경로 전달도 회귀 검사한다. 기존 산책·위치·지도·준비 체크리스트 검사도 실행한다.

기존 즐겨찾기와 개인 메모는 삭제하지 않는다. 브이월드 배경 지도 이미지 자체에 인쇄된 상호·지명은 앱이 추가하는 장소 핀과 별개이며, 이 필터로 배경 이미지의 글자를 지우지는 않는다.
