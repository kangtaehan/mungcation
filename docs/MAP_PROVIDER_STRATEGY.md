# 배경 지도·공원·도보 경로 분리

## 평가와 결정

브이월드 배경 지도 + 전국도시공원표준데이터 + 기존 도보 경로를 독립적으로 사용하는 구성을 채택한다. 국내 지명과 배경 지도 선택을 개선하면서 공원 정식 명칭, 반려동물 입장 자료, 산책 기록과 보상을 유지할 수 있다. 배경 지도를 바꿔도 검색·경로 서버는 변경하지 않는다.

- 브이월드 WMTS는 EPSG:3857 타일이며 현재 flutter_map 8.3.2의 기본 투영과 맞는다. 공식 예시의 순서는 `{z}/{y}/{x}`다. 앱의 장소 좌표와 경로는 계속 WGS84 위도·경도를 쓴다.
- 인증키가 없으면 작동 중인 지도를 유지한다. 인증키 설정 또는 `VWORLD_API_KEY` 빌드 설정으로 활성화한다. 웹 키는 브라우저에 보이므로 등록 도메인과 사용량 제한으로 관리한다. 다른 사람의 예제 키는 사용하지 않는다.
- 브이월드 장애 시 전체 배경 레이어를 기본 지도로 전환할 수 있다. 두 제공자의 타일을 섞지 않고 실제로 표시하는 배경 지도에 맞게 출처도 바꾼다.
- 브이월드 타일은 별도 허용 확인 전 앱의 영구 디스크 캐시에 저장하지 않는다. 브라우저 자체 HTTP 캐시와 앱의 오프라인 타일 저장을 구분한다.
- 공원 기준일은 지자체가 제공한 원래 날짜다. 배경 지도가 바뀌어도 자료를 새로 검증했다고 표시하지 않는다. 대표 좌표는 실제 보행 입구와 다를 수 있으므로 경로 종점 확인이 필요하다.

## 국내 도보 서비스 비교

| 서비스 | 판단 |
| --- | --- |
| 기존 FOSSGIS OSRM / iOS MapKit | 현재 동작과 안전성 판정을 유지한다. 배경 지도 변경과 분리한다. |
| TMAP 보행자 API | 첫 비교 후보. 공식 문서에 보행자 경로 API가 있고 무료 경로안내 한도가 있다. 등록 앱 키가 필요하며 사용량·약관·결과 저장 제한을 확인해야 한다. |
| NAVER Directions 5 | 공식 안내가 자동차 전용이므로 도보 비교 대상으로 호출하지 않는다. |
| 카카오모빌리티 도보 | 공식 담당자 안내상 유료 길찾기 제휴와 함께 도보 제휴가 필요하므로 즉시 무료 대체 대상으로 전환하지 않는다. |
| ROUTO 보행자 | 공개 문서에 지원 지역 목록과 거리 제한이 있어 전국 동일 커버리지로 가정하지 않는다. |

거리나 예상 시간이 짧다는 이유만으로 더 좋은 경로라고 판정하지 않는다. 육교·계단·횡단보도·공원 입구·반려동물 통행 제한과 실제 보행 가능성을 표본으로 확인해야 한다. 유모차 이용 가능 경로는 일반 보행자 경로와 별도로 검증한다. 지도 서비스 변경만으로 기존 미확인 경로가 안전하다고 바뀌지 않는다.

## 설정과 검증

프로필 → 지도 서비스 설정 → 브이월드 → 인증키 입력 → 저장. 앱·웹 모두 제공한다. 저장한 설정은 해당 기기/브라우저에만 적용되며 공원 자료와 도보 서버를 변경하지 않는다. 기본 지도 선택 시 웹·Android는 OSM, iPhone은 MapKit으로 돌아간다. iPhone에서도 브이월드 또는 사용자 지정 배경을 선택하면 공통 래스터 렌더러를 사용하고 검색·도보 경로는 계속 MapKit이 제공한다. 고급 검색·OSRM 설정은 웹·Android용이다.

배포 기본값은 `flutter build web --target lib/main_web.dart --release --base-href /mungcation/ --no-web-resources-cdn --dart-define=VWORLD_API_KEY=발급키`로 지정할 수 있다. 빌드 키가 없거나 형식이 잘못되면 기본 지도, 이미 저장한 사용자 선택이 있으면 그 선택을 우선한다. 웹 키는 JS 번들에 포함되므로 서버 비밀키처럼 취급하지 않고 발급 설정의 도메인 제한을 사용한다. 실제 키를 소스 파일이나 예제에 커밋하지 않는다.

GitHub Pages 자동 배포는 저장소 Actions 변수 `VWORLD_API_KEY`가 있으면 같은 빌드 설정으로 전달한다. 키가 없는 배포도 작동한다. 현재 공개 웹 주소는 `https://kangtaehan.github.io/mungcation/`이며 해당 서비스 주소에 맞는 발급 설정이 필요하다. 등록 URL·허용 호출 범위는 발급 화면에서 확인한다.

국내 경로 비교는 앱과 분리한 `tool/compare_walking_routes.py`로 실행한다. `TMAP_APP_KEY` 환경변수에 본인의 키를 설정하고 `python tool/compare_walking_routes.py --start 위도 경도 --end 위도 경도`를 실행한다. 기존 OSRM과 TMAP 보행자 API에 같은 좌표를 요청하고 거리·시간·출발점/종점 오차만 출력한다. 형상·주소·키를 보고서에 쓰지 않으며 자동으로 우승 제공자를 선택하지 않는다. 키가 없으면 TMAP 비교를 생략했다고 명시하고 불완전한 비교에는 실패 종료 코드를 반환한다. 결과물의 저장·이용 기간은 각 제공자 약관을 따른다.

발급키가 없는 상태에서는 브이월드 실제 타일과 TMAP 실제 경로의 비교가 끝났다고 보고하지 않는다. 현재 검증 범위는 키·URL·좌표 순서, 기존 설정 호환, 지도 전환·오류 복구·출처 표시, 원본 경로 보존, 응답 형식 검증과 자동 테스트다.
