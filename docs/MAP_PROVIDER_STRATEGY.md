# 배경 지도·공원·도보 경로 분리

## 평가와 결정

브이월드 배경 지도 + 전국도시공원표준데이터 + 기존 도보 경로를 독립적으로 사용하는 구성을 채택한다. 국내 지명과 배경 지도 선택을 개선하면서 공원 정식 명칭, 반려동물 입장 자료, 산책 기록과 보상을 유지할 수 있다. 배경 지도를 바꿔도 검색·경로 서버는 변경하지 않는다.

- 브이월드 WMTS는 EPSG:3857 타일이며 현재 flutter_map 8.3.2의 기본 투영과 맞는다. 공식 예시의 순서는 `{z}/{y}/{x}`다. 앱의 장소 좌표와 경로는 계속 WGS84 위도·경도를 쓴다.
- 인증키가 없으면 작동 중인 지도를 유지한다. 인증키 설정 또는 `VWORLD_API_KEY` 빌드 설정으로 활성화한다. 웹 키는 브라우저에 보이므로 등록 도메인과 사용량 제한으로 관리한다. 다른 사람의 예제 키는 사용하지 않는다.
- 브이월드 장애 시 전체 배경 레이어를 기본 지도로 전환할 수 있다. 두 제공자의 타일을 섞지 않고 실제로 표시하는 배경 지도에 맞게 출처도 바꾼다.
- 브이월드 타일은 별도 허용 확인 전 앱의 영구 디스크 캐시에 저장하지 않는다. 브라우저 자체 HTTP 캐시와 앱의 오프라인 타일 저장을 구분한다.
- 공원 기준일은 지자체가 제공한 원래 날짜다. 배경 지도가 바뀌어도 자료를 새로 검증했다고 표시하지 않는다. 대표 좌표는 실제 보행 입구와 다를 수 있으므로 경로 종점 확인이 필요하다.

## 국내 도보 서비스 비교

| 서비스 | 판단 |
| --- | --- |
| 기존 FOSSGIS OSRM / iOS MapKit | 현재 동작과 안전성 판정을 유지한다. 배경 지도 변경과 분리한다. |
| TMAP 보행자 API | 첫 비교 후보. 공식 문서에 보행자 경로 API가 있고 무료 경로안내 한도가 있다. 등록 앱 키가 필요하며 사용량·약관·결과 저장 제한을 확인해야 한다. |
| NAVER Directions 5 | 공식 안내가 자동차 전용이므로 도보 비교 대상으로 호출하지 않는다. |
| 카카오모빌리티 도보 | 공식 담당자 안내상 유료 길찾기 제휴와 함께 도보 제휴가 필요하므로 즉시 무료 대체 대상으로 전환하지 않는다. |
| ROUTO 보행자 | 공개 문서에 지원 지역 목록과 거리 제한이 있어 전국 동일 커버리지로 가정하지 않는다. |

거리나 예상 시간이 짧다는 이유만으로 더 좋은 경로라고 판정하지 않는다. 육교·계단·횡단보도·공원 입구·반려동물 통행 제한과 실제 보행 가능성을 표본으로 확인해야 한다. 유모차 이용 가능 경로는 일반 보행자 경로와 별도로 검증한다. 지도 서비스 변경만으로 기존 미확인 경로가 안전하다고 바뀌지 않는다.
