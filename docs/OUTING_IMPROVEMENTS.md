# 반려동물 외출 지도 개선

## 반영 내용

1. 장소 상세의 외출 준비 체크리스트: 목줄·하네스, 배변봉투, 물·물그릇, 이동수단·입장 조건 확인을 사용자가 직접 체크한다. 저장 버튼으로 즐겨찾기와 함께 저장하며, 개인 메모와 공식 입장 정책을 변경하지 않는다. 날짜가 지난 준비 항목은 다음 방문 시 체크를 해제해 오늘의 외출을 다시 확인하도록 한다.
2. 즐겨찾기의 종류별 필터: 공원·카페·음식점·공공문화·마트쇼핑·숙소·놀이터·동물병원을 네트워크 요청 없이 필터링한다. 검색 화면의 종류 선택과 분리해 검색 조건이 즐겨찾기에 의도치 않게 적용되지 않도록 한다. 오늘 저장한 준비 수 또는 다시 확인할 필요를 목록에서 표시한다.
3. 입장 규정의 원자료 날짜 강조: 기준일이 365일 이상 전이면 오래된 원자료임을 표시한다. 작성일이 없으면 미확인으로 표시하고, 최근 수집일이 오래된 규정을 새로 작성한 날짜처럼 보이게 하지 않는다. 날짜 때문에 동반 가능 여부를 임의로 바꾸지 않는다.
4. 장소 이름·주소 복사 버튼: 시설 문의나 동행자에게 장소를 전달할 때 사용한다.

## 저장과 호환

기존 SavedPlace에 선택 필드 preparation, preparedAt을 추가한다. 기존 즐겨찾기와 백업은 빈 준비 항목으로 읽는다. 허용된 준비 키만 받으며, 메모와 체크리스트를 각각 저장해도 다른 정보가 유지된다. 저장 실패 시 기존 데이터를 바꾸지 않는다. 즐겨찾기 해제 시 개인 메모뿐 아니라 준비 기록이 삭제되는 점도 확인한다. 준비 상태는 해당 기기/브라우저에 저장되며, 체크 완료는 시설의 입장 허용이나 경로 안전을 보장하지 않는다.

## 검증

직렬화·기존 자료 호환·메모 보존·쓰기 실패·잘못된 항목·지난 준비 기록 초기화·작은 화면/큰 글씨·오프라인 즐겨찾기 필터·수집일과 기준일 구분을 자동 검증한다. 기존 지도·산책·입장 정책 테스트도 함께 실행한다.
