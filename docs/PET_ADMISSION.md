# 반려동물 동반 장소와 입장 조건

## 사용자에게 제공할 기능

- 지도에 자료상 동반 가능한 음식점·카페·문화/공공시설·마트/쇼핑시설을 표시한다.
- 장소별 동반 규정, 유모차·캐리어·목줄·입마개 관련 내용, 크기 제한, 요금, 구역 제한, 자료 기준일과 출처를 보여준다.
- ‘유모차 또는 캐리어’처럼 선택 가능한 조건을 모두 필수로 바꾸지 않는다. 공개되지 않은 조건은 미확인으로 남긴다.
- 일반 검색 결과·개인 메모를 확인된 동반 정책과 구분한다. 같은 브랜드의 다른 지점에 정책을 복사하지 않는다.

## 데이터 출처와 범위

1. 한국문화정보원 전국 반려동물 동반 가능 문화시설 위치 데이터(15111389). 대상 카페·식당·미술관·박물관·문예회관·여행지의 동반 가능 여부와 제한사항 원문을 사용한다. 2022/2025 자료이므로 기준일을 숨기지 않는다. 실내/실외 공간 존재 여부만으로 해당 구역의 반려동물 입장을 허용한다고 판단하지 않는다.
2. 식품안전나라 반려동물 동반출입 등록 음식점 공개 현황. 이름과 도로명·건물번호·지역이 일치하는 실제 지도 장소에만 등록 정보를 연결한다. 좌표가 없는 등록 업소의 위치를 임의로 만들지 않는다. 준비물·구역 등 세부 규정은 별도 확인이 필요하다.
3. 공식 운영사에서 규정을 확인한 쇼핑 지점. 지점 주소·좌표·허용 구역·이동수단의 대체 관계·크기 제한을 수동 검증한 자료를 포함한다. 쇼핑몰 공용 공간의 허용을 입점 마트·음식점 전체의 허용으로 확대하지 않는다.
4. 한국관광공사 반려동물 동반여행 전용 API. 전국 표출 목록에서 9,631곳을 연결했다. 이 중 500곳의 상세 동반 규정을 확인했으며, 상세 미조회 장소는 목록 등재 근거와 조건 미확인을 구분한다. 비표출·잘못된 좌표는 제외한다. 기존 명시적 입장 제한·불가 자료를 단순 목록 등재 정보로 덮어쓰지 않는다. 관광정보 수정일을 규정 작성일로 간주하지 않는다.

## 구현·검증 순서

1. 공개 파일을 정제하고 명시적 가능/불가, 원문 조건, 기준일을 보존하는 테스트와 갱신 도구.
2. 입장 정책 모델·직렬화·출처별 카탈로그·안전한 지점 매칭·지도 서비스 연결.
3. 지도 필터·마커·추천 목록·장소 상세 화면과 준비물 안내.
4. 작은 화면·큰 글씨·자료 없는 장소·출입 불가·서로 다른 지점·저장/백업·기존 산책 테스트.
5. Chrome에서 실제 데이터 파일 조회, 웹 빌드의 파일 일치 검증 및 배포.

문화자료와 등록 현황은 공개 원본 갱신 도구로 갱신한다. 수동 검증한 운영사 규정은 실제로 다시 확인하기 전까지 확인일을 자동으로 갱신하지 않는다. 조회 당시 자료상 동반 가능이어도 운영 정책이 바뀔 수 있음을 방문 전 안내한다.

## 반영한 자료와 사용 방법

2026-11-18 수집본: 문화정보원 70,650행 중 카페·식당·공공문화·여행지·호텔·펜션 3,530개를 정제했다. 그중 동반 가능/조건부 가능은 2,319개다. 공식 쇼핑 지점 6개를 더해 동반 필터의 후보는 2,325개이며, 현재 위치 주변 8km 또는 입력한 지역·이름으로 조회한다. 불가·미확인 자료는 동반 가능 목록에서 제외한다.

쇼핑 자료는 IKEA 5개 지점과 스타필드 마켓 동탄점으로 시작한다. 전국 모든 대형마트의 허용을 보장하는 목록이 아니다. 동탄점은 몰 공용부와 개별 매장 규정이 다르며, 식품매장 전체의 입장을 허용한다고 표시하지 않는다. 실내외 공간 유무는 입장 가능 구역의 근거로 사용하지 않는다.

2026-11-20 14:50 기준으로 제공받은 업소현황 엑셀 2,935행에서 주소가 구조화된 2,921곳을 보존했다. 중복 10행을 정리했고, 도로명·건물번호 연결이 안 되는 4행은 별도 보류 목록으로 남겼다. 기존 목록보다 16곳이 추가되었다. 원본 파일명·SHA256·기준시각을 보존하며, 파일 기준시각은 업소별 규정 작성일이 아니다. 실제 음식점·카페 지도 결과와 이름·도로명·건물번호·지역이 하나의 지점으로 일치할 때만 연결한다. 좌표·준비물·몸무게·구역은 엑셀에 없으므로 추정하지 않는다. 문화자료의 원래 기준일은 2022-11-30 또는 2025-03-24이며, 수집일을 새 정책 확인일로 바꾸지 않는다.

지도에서 ‘동반 가능’, ‘음식점’, ‘카페’, ‘공공·문화’, ‘마트·쇼핑’을 선택한 뒤 장소 상세를 열면 규정·이동수단·허용 구역·크기·대여·요금·출처를 볼 수 있다. 일부 지도 조회가 실패해도 확보한 공개 장소는 계속 표시한다. 상세 화면은 기준일과 원문 링크를 제공하고 개인 메모와 구분한다.

갱신: `python tool/update_pet_places.py`. 월간 Pages 갱신도 같은 도구를 사용한다. 날짜 없는 온라인 목록에 이번 엑셀의 등록 업소가 누락되면 기존 엑셀 스냅샷을 유지한다. 기준시각이 확인된 새 엑셀은 `tool/import_pet_food_xlsx.py`로 갱신한다. 다운로드 서비스가 CAPTCHA를 요구하면 중단하며 우회하지 않는다. 원본 CSV/HTML/XLSX는 저장소에 포함하지 않는다. 관광공사 API의 키 설정·연결 시험과 엑셀 갱신 명령은 [연결 안내](TOUR_API_CONNECTION.md)를 참고한다.

검증: 전체 Flutter 테스트, Python 정제 테스트, Chrome 지도·정책·실제 자료 테스트, 빌드에 포함된 JSON 원본 일치 검증. `test/pet_admission_render.dart`는 실제 지점 자료로 화면을 렌더링하는 수동 시각 검증 도구다.
