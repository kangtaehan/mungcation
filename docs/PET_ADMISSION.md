# 반려동물 동반 장소와 입장 조건

## 사용자에게 제공할 기능

- 지도에 자료상 동반 가능한 음식점·카페·문화/공공시설·마트/쇼핑시설을 표시한다.
- 장소별 동반 규정, 유모차·캐리어·목줄·입마개 관련 내용, 크기 제한, 요금, 구역 제한, 자료 기준일과 출처를 보여준다.
- ‘유모차 또는 캐리어’처럼 선택 가능한 조건을 모두 필수로 바꾸지 않는다. 공개되지 않은 조건은 미확인으로 남긴다.
- 일반 검색 결과·개인 메모를 확인된 동반 정책과 구분한다. 같은 브랜드의 다른 지점에 정책을 복사하지 않는다.

## 데이터 출처와 범위

1. 한국문화정보원 전국 반려동물 동반 가능 문화시설 위치 데이터(15111389). 대상 카페·식당·미술관·박물관·문예회관·여행지의 동반 가능 여부와 제한사항 원문을 사용한다. 2022/2025 자료이므로 기준일을 숨기지 않는다. 실내/실외 공간 존재 여부만으로 해당 구역의 반려동물 입장을 허용한다고 판단하지 않는다.
2. 식품안전나라 반려동물 동반출입 등록 음식점 공개 현황. 이름과 도로명·건물번호·지역이 일치하는 실제 지도 장소에만 등록 정보를 연결한다. 좌표가 없는 등록 업소의 위치를 임의로 만들지 않는다. 준비물·구역 등 세부 규정은 별도 확인이 필요하다.
3. 공식 운영사에서 규정을 확인한 쇼핑 지점. 지점 주소·좌표·허용 구역·이동수단의 대체 관계·크기 제한을 수동 검증한 자료를 포함한다. 쇼핑몰 공용 공간의 허용을 입점 마트·음식점 전체의 허용으로 확대하지 않는다.

## 구현·검증 순서

1. 공개 파일을 정제하고 명시적 가능/불가, 원문 조건, 기준일을 보존하는 테스트와 갱신 도구.
2. 입장 정책 모델·직렬화·출처별 카탈로그·안전한 지점 매칭·지도 서비스 연결.
3. 지도 필터·마커·추천 목록·장소 상세 화면과 준비물 안내.
4. 작은 화면·큰 글씨·자료 없는 장소·출입 불가·서로 다른 지점·저장/백업·기존 산책 테스트.
5. Chrome에서 실제 데이터 파일 조회, 웹 빌드의 파일 일치 검증 및 배포.

문화자료와 등록 현황은 공개 원본 갱신 도구로 갱신한다. 수동 검증한 운영사 규정은 실제로 다시 확인하기 전까지 확인일을 자동으로 갱신하지 않는다. 조회 당시 자료상 동반 가능이어도 운영 정책이 바뀔 수 있음을 방문 전 안내한다.
