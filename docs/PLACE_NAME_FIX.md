# 장소 이름 전체 표시 — 2026-11-18

## 변경

- 웹·Android 지도 이름표의 한 줄 말줄임과 고정 높이를 제거했다. 화면 너비·실제 글자 크기로 이름과 설명의 높이를 계산하고 핀 위에 표시한다.
- 현재 위치 아이콘보다 장소 이름표를 나중에 그려 이름이 가려지거나 터치되지 않는 문제를 해결했다.
- 추천 장소는 고정 높이 가로 카드 대신 내용에 맞춰 높아지는 세로 카드로 표시한다. 제목·산책 안내·검색 결과 주소의 말줄임도 제거했다.
- 장소 검색·즐겨찾기·상세·목적지·방문 기록에서 같은 표시 이름을 사용한다. 예전 저장 데이터의 이름이 빈 문자열인 경우도 주소 또는 `이름 정보 없음`으로 표시한다.
- Nominatim은 `namedetails=1`을 요청해 한국어 이름을 우선 사용한다. 이름이 없을 때 반환된 전체 주소를 보이며 이름을 임의로 만들지 않는다.
- iOS 지도도 여러 줄 이름표와 전체 이름 설명을 사용하고, 이름이 비어 있으면 주소를 사용하도록 수정했다. Swift 컴파일과 실제 화면은 macOS CI·기기 검증 대상으로 남긴다.

## 검증

- 전체 Dart 정적 분석: 오류·경고 없음.
- Flutter 전체 테스트: 83개 통과.
- 긴 공원명·긴 설명·글자 크기 2배·320px 지도·이름표 터치·추천 카드 줄바꿈·빈 이름 응답·예전 저장 데이터의 주소 대체 표시를 검증했다.
- GitHub Pages 배포 전에 실제 Chrome에서 지도 이름표 테스트도 실행하도록 추가했다.
- 기존 Chrome 사진 안내 테스트는 안내가 화면 아래에 있을 때 스크롤한 뒤 확인하도록 수정했다.

이 수정은 검색되거나 저장된 장소의 이름 표시를 다룬다. 지도 공급자에 이름 자체가 없거나 검색되지 않은 모든 지형의 이름을 새로 제공하는 기능은 아니다. 기본 지도 타일에 인쇄된 글자는 지도 공급자가 정한다. 가까운 장소의 이름표가 겹치면 지도를 확대하거나 전체 이름이 표시된 목록에서 확인할 수 있다.
