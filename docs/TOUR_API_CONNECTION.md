# 한국관광공사 반려동물 동반여행 API 연결 방법

공식 서비스: https://www.data.go.kr/data/15135102/openapi.do

기본 주소: `https://apis.data.go.kr/B551011/KorPetTourService2`

## 인증키 설정과 연결 시험

1. 활용신청 현황에서 이 서비스가 승인되었는지 확인한다.
2. 발급받은 일반 인증키 중 Decoding 키를 복사한다. 브이월드 키와 다른 키다.
3. Git에서 제외된 `config/app_keys.json`에 `TOUR_API_KEY` 항목을 추가한다. 기존 `VWORLD_API_KEY` 값은 유지한다. 예시 구조는 `config/app_keys.example.json`에 있다. 실제 키를 예제 파일·소스·문서·채팅에 적지 않는다.
4. 프로젝트 폴더에서 아래 명령을 실행한다. 환경변수 `TOUR_API_KEY`로 전달할 수도 있다.

```powershell
python tool/check_pet_tour_connection.py --lat 37.445 --lon 129.165 --radius 8000
```

삼척 시내의 예시 좌표 주변 8km를 거리순으로 최대 20건 조회한다. 키를 명령줄에 직접 쓰지 않고, 요청 주소나 인증키를 출력하지 않는다. 한 번의 위치기반 조회를 실행하며, 인증 성공과 결과 0건은 구분한다. 승인·인증·할당량 오류를 장소 없음으로 취급하지 않는다.

성공 시 공공 API 응답을 `artifacts/verification/pet_tour_probe.json`에 저장한다. 이 도구는 연결 시험용이며 기존 지도 자료를 자동 교체하지 않는다. 현재 관광공사 키를 제공받지 않았으므로 실제 인증 호출 성공은 아직 확인하지 않았다. 기존 지도·공원·도보 경로에는 이 키가 필수가 아니다.

## 지도 반영 순서

1. 위치기반 `locationBasedList2`로 장소 목록을 받는다. `mapX`는 경도, `mapY`는 위도이며 반경 단위는 미터다.
2. 각 장소의 `contentid`를 상세 조회 요청의 `contentId`에 전달한다. `detailPetTour2`로 동반 조건, `detailCommon2`로 공통 정보, 필요한 경우 이미지·소개 정보를 조회한다. 요청 변수의 대소문자를 구분한다.
3. 실제 응답에 있는 조건·허용 구역·크기 제한 등을 보존한다. 설명이나 운영시간이 존재한다는 이유만으로 출입 가능을 확정하지 않는다. 세부 조건이 없으면 미확인으로 남긴다.
4. 기존 공공데이터 공원은 유지하고 동반 매장 자료만 보강한다. 동일 브랜드의 다른 지점에 규정을 복사하거나, 주소만 있는 자료에 좌표를 임의로 만들지 않는다.
5. 페이지를 나누어 조회하고 기능별 호출 한도에 맞춰 저장·갱신한다. 동기화 목록의 표출 중지 자료는 지도에서 제외한다. 이미지 이용조건도 확인한다.

서버를 아직 구축하지 않은 현재 단계에서는 인증키로 자료를 내려받아 검증한 뒤 앱 번들에 포함하는 방식이 적합하다. 이 경우 사용자마다 API를 호출하지 않으며, 주기적으로 자료를 갱신하고 웹·앱을 다시 배포한다. 실시간 서버 프록시는 회원·서버 구축을 진행할 때 별도로 구현한다.

## 제공 엑셀로 음식점 등록목록 갱신

```powershell
python tool/import_pet_food_xlsx.py "C:\Users\강태한\Downloads\반려동물_동반가능_업소현황(2026.11.20 14시50분 기준).xlsx" --as-of "2026-11-20T14:50:00+09:00"
```

원본 엑셀은 읽기만 하고 등록목록 JSON 한 개를 갱신한다. 필수 열 누락·수식 포함·지나치게 작은 전국 목록은 거부한다. 원본 파일명·SHA256·파일 기준시각을 보존한다. 파일 기준일은 개별 업소의 입장 규정 작성일과 다르다.

이번 파일의 2,935행은 유효 등록 2,921곳, 중복 10행, 도로명·건물번호 연결 보류 4행으로 정리했다. 기존 2,905곳에서 16곳이 추가되었고 기존 지점 삭제는 없다. 등록목록에는 좌표·유모차·캐리어 조건이 없으므로, 이름·주소가 정확히 일치하는 실제 지도 매장에만 연결한다. 상세 조건과 명시적인 출입 제한을 등록 정보로 덮어쓰지 않는다.

날짜가 없는 온라인 목록이 이 날짜 있는 엑셀의 업소 일부를 누락시키면 기존 엑셀 스냅샷을 유지한다. 삭제를 반영하려면 기준시각을 확인한 새 전체 엑셀을 가져온다. 등록 현황도 바뀔 수 있으므로 시설의 실제 운영 규정과 동일하다고 표현하지 않는다.
