# 멍케이션 안정화 계획

현재 로컬 중심 앱의 백업 접근, 왕복 안내, 안전 정보, 웹 지원과 검증 경로를 개선한다. 계정·클라우드·AI 서버 추가 및 실제 스토어 배포는 별도 범위다.

1. 백업 접근: 마이와 저장 오류 화면에서 백업 화면 진입. 앱 시작점 회귀 테스트로 확인.
2. 왕복 안내: 진행 방향과 원래 출발점 유지, 구간 투영으로 이탈 판단. 같은 길 귀환·재탐색 테스트.
3. 안내 정리: 도로 이름을 인도 확인으로 해석하지 않음. 예상 추천 시간과 공급자 경로 시간 구분.
4. 플랫폼 정리: 모바일 전용 사진·파일·잠금 화면 기능은 웹에서 제한 안내. 웹 링크는 브라우저로 열기.
5. 자동 검사: PR 분석·전체 테스트·Android/web 빌드, macOS iOS unsigned 빌드와 네이티브 테스트.
6. 문서: 지원표·검증 결과·출시 선행 조건 갱신. 실제 기기, 계정, 공급자 계약이 필요한 작업은 미검증으로 명시.

각 단계는 집중 테스트 후 전체 분석·테스트·가능한 플랫폼 빌드로 검증한다. 기존 사용자 데이터 스키마와 미추적 검증 이미지를 보존한다.
